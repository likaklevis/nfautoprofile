Manual installation

Chromium browsers

Chrome, Edge, Brave, Opera, any Chromium browser.

  1. Download the Chromium ZIP and unzip it.
  2. Open your browser's extensions page and turn on Developer mode.
  3. Choose Load unpacked and select the unzipped folder.
Firefox

Manual installs are removed when Firefox restarts.

  1. Download the Firefox ZIP. Do not unzip it.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and select the downloaded ZIP file.
