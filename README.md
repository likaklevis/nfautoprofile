# NF Auto Profile

Browser extension that automatically opens your Netflix profile and enters its saved PIN.

```text
Profile chooser → select saved profile ID → enter PIN if needed → save → profile opens
```

## Install

- [Firefox](https://addons.mozilla.org/firefox/addon/nfautoprofile/)
- [Opera](https://addons.opera.com/extensions/details/nf-auto-profile/)

## OR

## Manual Setup

Download the ZIP for your browser from [Releases](https://github.com/likaklevis/nfautoprofile/releases/latest).

- Firefox: open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select the Firefox ZIP. **The manual installation limitation by Firefox, removes the extension when closing the browser.**
- Chrome / Chromium / Edge / Brave / Opera: unzip the Chromium ZIP, enable **Developer mode** on your browser’s extensions page, and choose **Load unpacked**. Select the unzipped folder.
